OCR 쪽으로 깊게 연구로 유명하신 백영민 전문가님

협업? 연구 주제? Licence Plate Detection

프로젝트와 연구가 엮여있는 형태 / OCR 태스크와는 약간 떨어져 있지만, 번호판 인식임. 이건 서브 주제로 가져가고, 상호 디텍션이라고 생각하면 됨.

자동차 plane detection할 때 시간에 따른 변화들을 test-time adaptation을 통해 강인하게 보정할 수 있을까?

가볍게 yolo 기반 상용 detector + TTA 적용해서 여러가지 상황에 강인하게 adaptation을 만들 수 있지 않을까 하는 것이 교수님 생각

recognition? 포함되있긴 하지만, 그거 자체를 adaptation하는 거 자체는 어려울 거 같아 글자들로만 한정하고자 함. 글자들 각각 디텍션? 넘버 디텍션에 가까움. 각각의 글자들을. 기본적으로 OCR detection을 깔고 감.

문제 난이도? 조도 변화, 날씨 변화 등에 따라 어느 정도 빈도로 발생하는지. 최근 딥러닝 기반 디텍터는 그런 상황을 많이 커버하고 있음.

기존 전전 회사에 ai 바우처로 나온 건. legacy였는데 해결하는 김에 detector + tta로 방향 잡아 해결하고자 함. tta 자체가 번호판 인식에 대해서는 강인한 detector 사용 시 잘 잡히지 않을까 생각하긴 함.

새로운 방법을 제안하고 나서 기존 방법보다 좋다고 주장할 수 있는 데이터셋이 있나? tta에 가까운 주제라고 생각.

Fully Test-time Adaptation for Object Detection 논문? Cityscapes to ACDC가 이 논문에서 활용하는 데이터셋. 이정도 형태로 tta + pixelwise classification 데이터셋이 있는 것 같음.

TTA가 fine tuning 없이 모델 weight를 바꿔서 robust를 확보? adaptation이 되긴 하는데, test time에 들어오는 레이블을 알 수 없음. unlabeled finetuning을 하긴 한다고 함.

ocr 도메인에서는, 글자를 생성하기 위해 systhetic generation 사용하는데, domain 갭을 줄이는 연구 많이 있었음.

Line Plate 한정하면 paper가 될 것 같진 않음. detection, ocr 포함해서 tta 환경을 조성한 다음 문제를 동시에 푸는 것이 의미 있을까? yolov7 기반으로 하는게 많이 있음. 그렇게 풀어보는건? ⇒ ocr 특화 detector를 쓸 수 있지만, 그럼 ocr 특화로 갈 수 있고, 범용 detector를 쓰면 ocr에 맞게 튜닝을 진행해야 할 것 같음.

Detection만 하는건 아니고 글자 인식까지 하면, Line Plate 생성 자체는 쉬움. 예전 연구인데, 일본에서도 자동차 번호판 인식이 필요해 한 적 있음. repo 공개 한적 있음. 번호판 수집이 어려우니까, python으로 막 생성함. 실제 real data에서 검출. data plate 생성하고, 랜덤 배경에 붙여 detection 함. 번호판 생기다 보니 글자 위치 다 알 수 있었음. 데이터 생성해봤고 end-to-end ocr 모델에 합성했는데, 번호판 인식 잘되는 걸 확인할 수 있음.

synthetic data만으로도 잘된다는 느낌이 있음. 실제 데이터에서도 잘 됐던거 같음. **이미지 자체가 블러 되있거나 어두운 환경 등에서 인식률이 떨어짐.** 일본에서는 번호판 수집이 불가해서 synthetic으로만 했는데, 80% 정확도 정도로 종료되긴 함. 일본은 데이터 수집에 대한 규제가 많아서, 이러한 기법이 필요함.

날씨, 조도 같은 환경변화에 강인한 모델을 만드는 것도 중요한데, 데이터셋을 한정하면 어려울 것 같음. domain adaptation으로 확장하며 키워보는 것도 중요하다. e2e ocr 등으로 좁힌 다음 실험하거나, benchmark 데이터셋 확보를 위해 생성 모델로 생성? 가상의 어려운 상황들 등. ChatGPT로.

해당하는 데이터 구비하는게 큰 작업이 될 거 같음. 일단 synthetic, real 데이터. 우리나라는 어딘가 올라오는 게 있을거임. + public dataset 까지 해서 시작을 해볼 것. 번호판 adaptation 해봐야 크게 차이 안날 것 같음.

간판 등 이슈? 환경 변화 등이 이슈가 될 수 있음. 연구 주제로 삼기에는 좀 더 범용적인 주제가 좋긴함. specific한 topic이긴 한데, scope 너무 넓으면 오히려 힘들 수 도 있음 **첫 논문**이라. cityscapes 등 쪽으로 domain adaptation 적용하거나 발전시키는 방향으로 진행하는 것이 좋을 듯.

general한 도메인 잡고, synthetic to real, general adaptation 등 추가할 예정. specific한거는 sub로 들어가고, 환경 변화 등에 대한 adaptation은 조금 뒤로. domain adaptation과 얼마나 연관이 있는지? 실제 과제에서 scope로 잡고 있는것과 딱 맞는게 좋긴 함.

목표는 최대한 환경 변화에 강인한 detector를 만드는 것. adaptation 등은 synthetic to real이 가장 활용도 높지 않을까? synthetic data 생성 등. 그 느낌을 살릴가먄 domain adaptation을 좀 강화하는 방향? 최근 논문 중 [https://scholar.google.com/citations?view_op=view_citation&hl=ko&user=cV4h5MsAAAAJ&citation_for_view=cV4h5MsAAAAJ:0EnyYjriUFMC](https://scholar.google.com/citations?view_op=view_citation&hl=ko&user=cV4h5MsAAAAJ&citation_for_view=cV4h5MsAAAAJ:0EnyYjriUFMC) 이런게 있음. tta랑은 조금 다르게 접근. domain gap을 줄이는 것. 시험끝나고 나중에 좀더 읽어봐야지 - 어차피 리뷰 필요함~

어떻게 쓰이고 있는지 훑어보는거 중요함. 앞으로의 미팅? 사실 연구 과제에 가까움. 논문도 쓰는겸. 회사에서 소스코드 등의 공유가 필요하진 않음. 가이드 부탁드렸음. 여러 회사 현업에 계신 분들과 상의 후 가이드 진행받을 듯.
