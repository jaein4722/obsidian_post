	- 다만 학습에 5일(step1 2.5일 + step2 2.5일) 소요, 테스트에도 1시간 반 정도 걸려서 상당히 많은 시간 요구
	- 코드 최적화? aligning, 즉 distillation 과정이 오래 걸리는 것이므로, multi-gpu 지원되도록 개조만 해도 시간이 배로 줄어들 것 같긴함.
	- **50% pruned** 모델 평가했을 때 mIoU 74.11%, **논문 경향성과 일치**
	- **77% pruned** (<u>사전 제공 가중치</u>) 평가했을 때 mIoU 69.37%, **논문 경향성과 일치**
- 재현 실험 완료 후 SAM 기반 경량화 모델들의 트렌드? 분석
	- Quantization
		- PTQ4SAM: SAM에 적용 가능한 PTQ 프레임워크. SAM-L 6bit 양자화 시 무손실. CVPR 2024
		- PQ-SAM: SAM의 4bit PTQ를 실용적인 수준에서 달성. ECCV 2024
		- Mix-QSAM: Mixed Precision 기반 quantization. CVPRW 2025
	- Distillation
		- TinySAM: hard prompting sampling을 통해 전 stage를 distillation
	- Architecture
		- MobileSAM: ViT-H를 TinyViT로 교체. decoupled distillation이 핵심.
		- EfficientViT-SAM: EfficientViT를 사용해 가속화
		- FastSAM: 트랜스포머 대신 CNN 기반 접근
	- Pruning
		- SlimSAM: alterante slimming framework로 번갈아가며 pruning이 핵심.
	- Mixed precision, distillation
		- EfficientSAM: SAM-guided Masked Image pretraining을 통한 훈련

- SlimSAM(pruning 기반) + PTQ4SAM(quantization 기반) 융합 시 성능이 잘 나올까?
	- 아직 논문을 읽어보지는 않았지만, PTQ4SAM이 SAM 분포를 조절하는 식으로 calibration을 수행한다고 함. SlimSAM은 SAM의 원본 지식을 재사용하므로 같은 방식의 quantization을 적용할 수 있을 것
	- Q-SAM2의 PTQ 기반 calibration 아이디어도 흥미로움. SAM2가 기반을 SAM에 두고 있으니 비슷한 방법의 quantization이 가능하지 않을까 추측됨.
