얼굴 디텍터 중에 모델 사이즈 문제 됐던 게 있음.

EXTD: 백본 갈아끼워가지고 구현한건데, 차곡차곡 쌓이면서 s=2일때마다 feature map 절반으로 줄음. face detector 경우에는 하나 블럭을 계속 재사용해도 됨. RNN처럼 recurrent하게 돌리는 느낌. 실제 onnx로 변환하면 특수 operation이므로 비효율적일 것임. 하지마 파라미터를 드라마틱하게 줄일 수 있음. 재사용하면 되니까. 다양한 네트워크를 쓰는 대신 1/6로 조그만하게 reuse 가능. 디텍터 특히 뒷부분 백본이 은근 변화가 없기 때문.

여기서는 feature map 사이즈가 변하진 않는데, 1x1 conv나 이런것들 달면 변화가 있을 수 있음. 이런 식으로 하면 yolo 사이즈를 dramatic하게 줄여보는 거라면 시도해볼만한 것.

문제는 19년도임. conv로만 되있기 때문에 이펙트가 전혀 없음. 따라서 ViT에도 이런 방식의 reuse가 가능한지 검증해볼 필요 있음. 어느정도까지 파라미터를 재활용이 가능한지.

결과 나오게 튜닝할 수 있으면 바로 paper 갈수도 있음.
